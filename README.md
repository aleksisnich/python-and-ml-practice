# Python Course & Practice

Учебный репозиторий с практическими заданиями и небольшими проектами по Python-разработке, работе с данными, web-технологиям и машинному обучению.

## Содержание

### Python Basics
Базовые конструкции Python, работа со структурами данных, функциями и небольшими учебными задачами.

`python_basics/`

### Databases
SQL-запросы и задания по работе с базами данных.

`databases/`

### Data Engineering
Учебные задачи по обработке и преобразованию данных.

`data_engineering/`

### Web
Практика работы с HTTP, API, web scraping, Selenium и Scrapy.

`web/`

### Machine Learning
Учебные эксперименты с TensorFlow, PyTorch и нейронными сетями.

`ml/`

### LLM
Небольшие эксперименты с языковыми моделями и API.

`llm/`

### Numerical Methods
Численные методы, NumPy, SciPy и визуализация результатов.

`numerical_methods/`

### Mini Projects
Небольшие самостоятельные проекты и учебные приложения.

`mini_projects/`

## About

Репозиторий создавался в процессе обучения и содержит работы разных этапов — от базовых задач на Python до небольших проектов, работы с API, web scraping и экспериментов с ML.

Некоторые проекты и исследовательские разработки, выполненные в рамках профессиональной деятельности, не публикуются из-за ограничений на распространение исходного кода.
